# Descripción
Consulta a través de la plataforma API Auto Seguro
si un vehículo tiene encargo por robo
. Este servicio te permite verificar en segundos antes de comprarlo o circular con él.
Además, el sitio web entrega
recomendaciones para prevenir robos
, denunciar un vehículo sustraído y detectar posibles casos de clonación vehicular.
Haz tu consulta durante todo el año a través del
sitio web API Auto Seguro
.
Revisa los antecedentes requeridos
Para consultar los datos de un vehículo motorizado no necesitas ningún documento, solamente debes conocer uno de los siguientes datos:
La placa patente.
El VIN (número de chasis).
El número del motor del vehículo.
Consulta los datos de un vehículo
Comprueba si un vehículo tiene encargo por robo a través del
sitio web de Auto Seguro
.
Si la información contiene alguna imprecisión,
completa el formulario de antecedentes
destinado al registro y análisis de inconvenientes asociados a encargos y soluciones de vehículos.
Información proporcionada por
Carabineros de Chile
